# 为什么做 Element Plus Suite

Element Plus 的表格组件已经覆盖了绝大多数展示场景。真正进入业务页面后，重复出现的是另一类代码：列配置写一遍、分页状态维护一遍、远程加载和请求取消再写一遍。

Element Plus Suite 把这些稳定的重复工作抽出来，但不替页面决定业务规则。

## 它解决什么

- **列定义更集中**：用 columns 描述表头、列宽、插槽和分组列。
- **分页有默认值**：不配置时直接可用，需要关闭时传 `pagination="false"`。
- **远程请求有统一入口**：request 接收页码、每页条数和取消信号，返回 data 与 total。
- **原生能力不丢失**：ElTable 的属性、事件和实例方法仍然可用。

## 它不接管什么

排序、筛选和查询条件仍然属于业务页面。组件不会猜测你的接口参数，也不会替你维护筛选状态。这样做的好处是，任何请求方式和数据结构都可以接入，同时不会把业务逻辑藏进组件内部。

> Element Plus Suite 是非官方社区项目，不是 Element Plus 官方产品。
