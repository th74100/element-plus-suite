# Element Plus Suite

Element Plus Suite 是基于 Element Plus 二次封装的组件库，开箱即用。可以显著地提升制作 CRUD 页面的效率，轻松搬砖。

## 特性

- **🚀 高效开发**：提供常用业务组件，减少重复代码
- **🎯 灵活配置**：支持 JSON 配置式和模版式，满足不同场景需求
- **💪 TypeScript**：提供完整的类型定义，更好的开发体验
- **🔥 Element Plus**：基于 Element Plus，支持主题定制
