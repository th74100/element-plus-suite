# skills.md

Element Plus Suite 提供标准 Agent Skills 目录，可通过 Skills CLI 安装到 Codex、Claude Code、Cursor 等支持 Agent Skills 的工具。

## 安装

```bash
npx skills add th74100/element-plus-suite
```
